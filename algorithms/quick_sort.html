Quick Sort Algorithm Visualization

QuickSort is a divide-and-conquer algorithm that sorts an array by selecting a "pivot" element, partitioning the array into two parts (elements less than the pivot and elements greater than the pivot), and recursively sorting the two parts.

Time and Space Complexity

Time Complexity:

  • Worst-case: O(n2) - occurs when the pivot always results in unbalanced partitions, for example when the array is already sorted or reversed.
  • Best-case: O(n log n) - occurs when the pivot divides the array into two roughly equal parts.
  • Average-case: O(n log n) - happens in most random scenarios where the pivot divides the array into reasonably balanced partitions.

Space Complexity:

  • O(log n) - the recursive call stack space used when QuickSort divides the array in half each time.

Python Code for QuickSort Algorithm

# Python code to implement QuickSort without using any functions

def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[-1]  # Using the last element as pivot
    left = [x for x in arr[:-1] if x < pivot]
    right = [x for x in arr[:-1] if x >= pivot]
    return quick_sort(left) + [pivot] + quick_sort(right)

# Example array to sort
arr = [6, 5, 3, 1, 8, 7, 2, 4]
sorted_arr = quick_sort(arr)
print("Sorted Array:", sorted_arr)
